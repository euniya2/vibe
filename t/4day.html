7팀 살펴보기 넣기

ChatGPT 새 채팅 · 대시보드_V1.html 파일을 첨부하고 아래 프롬프트를 보냅니다

첨부한 대시보드에 「팀 살펴보기」 칸을 추가합니다.
칸 1·2·3의 내용과 기능은 그대로 둘 것. 단, 아래 [좁은 칸의 판단 도구]에 적은 것은 고칠 것.

[배치]
- 칸 2·3 오른쪽에 세 번째 칸으로 넣고, 아래 세 칸을 같은 폭, 같은 높이로 맞출 것
- 세 칸의 높이는 칸 2 「팀별 비교」 내용 높이에 맞출 것. 칸 2에 빈 공간이 많이 남지 않게
- 칸이 좁아져도 칸 3의 그래프는 칸의 폭과 남은 높이를 모두 채우게 다시 그릴 것
- 팀 살펴보기 칸은 옆 칸과 높이를 맞추고, 목록이 넘치면 목록 부분만 칸 안에서 스크롤할 것. 전환 버튼은 위에 고정
- 아래 세 칸은 지금보다 80px 높게 하고, 세 칸 높이는 같게 할 것. 늘어난 높이는 칸 안 내용이 고르게 나눠 쓸 것

[좁은 칸의 판단 도구]
- 공헌이익 기준 그래프: 빨간 팀만 이름을 자기 점 바로 옆에 쓰고, 나머지는 회색 점만. 회색 점에 마우스를 올리면 이름이 뜨게 하고, 마우스 감지 범위만 점 둘레로 넓힐 것
- 가로 눈금은 20% 단위, 세로축 제목은 가로로, 가로축 제목은 눈금 숫자와 한 줄 띄울 것. 오른쪽 끝 140%가 잘리지 않게
- 기준 입력 칸은 [표] [그래프] 버튼과 한 줄에 둘 것
- 등급 구간: 입력은 항상 두 줄로 고정. 첫 줄 S ≥ [ ]%, A ≥ [ ]%, 둘째 줄 B ≥ [ ]%, C ≥ [ ]%, D: C 미만. [표] [그래프] 버튼은 첫 줄 오른쪽 끝. 등급 글자(S ≥ 등)는 13px 굵게, %와 'D: C 미만'은 12px, 입력 칸은 숫자 세 자리가 잘리지 않게 최소 52px
- 전년 대비: 팀 이름 12px, 증감률 숫자는 화살표 끝 바로 옆, '감소 기준' 이름표가 칸 밖으로 잘리지 않게
- 범위를 벗어난 점의 이름표(예: 선물세트 공헌이익 52.0% ◀ · 판로지원액 134.9% ▲)가 칸 밖으로 잘리지 않게, 길면 두 줄로 나눌 것

[팀 살펴보기]
- 위쪽에 전환 버튼 5개: [점검 필요] [공헌이익 미달] [전년보다 감소] [우수] [전체]. 버튼마다 해당 팀 수 표시
- 기준은 칸 3 「판단 도구」의 값을 그대로 쓸 것. 칸 3에서 기준을 바꾸면 목록도 바로 바뀔 것
  · 점검 필요: 등급이 C 이하이거나, 공헌이익 기준에 못 미친 팀
  · 공헌이익 미달: 공헌이익 기준에 못 미친 팀
  · 전년보다 감소: 전년 대비 감소 기준 이상 줄어든 팀 (칸 3에 전년 대비가 없으면 5%)
  · 우수: 등급이 S이고 공헌이익 기준을 지킨 팀
  (칸 3에 등급 구간이 없으면 처음 값 S 100% 이상, C 85% 미만으로 계산할 것)
- 표가 아니라 팀마다 목록 한 칸으로 보여 줄 것
  · 첫 줄: 팀 이름, 해당 기준 색 표시(C 등급 이하 빨강, 공헌이익 미달 빨강, 전년 감소 주황, 우수 초록), 오른쪽 끝에 '회의에서 다룰 팀' 체크
  · 둘째 줄: 작게 달성률 · 공헌이익 달성률 · 전년 대비, 비고가 있으면 그 아래
  · 맨 아래: '확인할 것' 메모 칸(한 줄 입력칸)

[데이터 표]
- 맨 아래 데이터 표는 처음에는 접어 두고, [데이터 표 보기] 버튼으로 펼칠 수 있게 할 것

[필수 조건]
- 데이터를 넣기 전에는 "데이터를 넣으면 팀 목록이 나타납니다" 표시
- 외부 라이브러리 없이, 인터넷 없이도 열릴 것
- 기존 기능(데이터 넣기·지우기·저장 방식 포함)은 그대로 둘 것
- 넣은 데이터와 메모는 밖으로 보내지 말 것
- 수정한 전체 파일을 .html로 내려받을 수 있게 할 것
⏳ 기다리는 동안 먼저 부를 팀 1곳과 이유를 적어 보세요. 다음 단계에서 AI에게 물을 때 씁니다.

만들어지면

데이터를 넣고, 버튼 4개를 차례로 눌러 봅니다.
위에 적은 팀을 찾아 '회의에서 다룰 팀'에 체크합니다. 함께 다룰 팀이 있으면 더 체크합니다.

8AI로 확인할 질문 뽑기

ChatGPT 새 채팅 · 숫자는 넣지 않습니다. 상황만 말로 넣습니다

넓은 질문 무엇을 봐야 하나

팀별 판로지원액(목표, 실적, 전년 실적)과 공헌이익(목표, 실적)을 대시보드로 본다.
본부장의 관점에서 볼 포인트를 정리할 것.

[요청]
1. 먼저 확인할 순서 (3단계)
2. 숫자 조합별로 의심해 볼 점 3가지 (예: 달성률은 높은데 공헌이익이 목표에 못 미친 경우)
3. 팀장에게 물어볼 질문 3개

[필수 조건]
- 표 없이, 항목마다 한 줄로 짧게
⏳ AI가 답하는 동안 아래에서 상황 하나를 고르고, 내 판단을 한 줄 적어 보세요.

구체적인 질문 내 판단의 빈틈 찾기

7단계에서 '회의에서 다룰 팀'으로 체크한 팀에 맞는 상황을 고르세요

알고 있는 사정이 있나요? 선택 · 비고에 적힌 이유 등. 비워 두면 '알려진 이유는 없다'로 들어갑니다

이 상황에서 나는 어떻게 하려고 하나요? '무엇을 하겠다 + 왜'로 적으면 답이 날카로워집니다

예) 목표 넘김 · 공헌이익 미달 팀이라면
· 너그럽게: 목표를 넘겼고 방송 추가라는 이유도 있으니, 이번 공헌이익 미달은 인정하고 넘어가겠다.
· 엄격하게: 많이 팔아도 남는 것이 적으면 의미가 줄어드니, 할인·방송비를 다시 따져 보라고 하겠다.
· 조건 걸기: 방송 추가가 이번 한 번이면 인정하고, 다음 달에도 반복되면 판매 조건을 다시 짜겠다.
상황을 고르고 내 판단을 적으면 아래 프롬프트가 완성됩니다.
본부장의 관점에서 답할 것.

[상황] (위에서 고른 상황이 여기에 들어갑니다)
[내 판단] (위에 적은 내 판단이 여기에 들어갑니다)

[요청]
1. 이 판단이 틀릴 수 있는 경우 2개
2. 팀장에게 꼭 확인할 질문 3개

[필수 조건]
- 일반론 말고 이 상황에 맞춰 답할 것
- 항목마다 한 문장으로 짧게
- 알 수 없는 원인은 단정하지 말고 '확인 필요'로 표시

AI의 답에서 회의에 가져갈 질문 2~3개를 골라 적으세요

고른 질문을 대시보드 「팀 살펴보기」의 '확인할 것' 메모 칸에도 옮겨 적습니다. 다음 단계에서 회의 자료에 들어갑니다.

9회의 자료 만들기

7단계와 같은 채팅에서 이어서 · 지금까지의 판단을 한 장으로 내보냅니다

지금 대시보드에 [회의 자료 만들기] 버튼을 추가합니다.
기존 화면과 기능은 그대로 둘 것.

[회의 자료]
- 버튼 위치: 맨 위 [데이터 넣기] 옆
- 누르면 한 장짜리 회의 자료가 화면 위에 뜰 것. 창은 A4 한 장처럼 넓게 할 것
- 담을 내용
  1. 제목과 오늘 날짜
  2. 꼭 볼 숫자: 칸 1의 카드 값
  3. 우수 사례: 「팀 살펴보기」의 우수 팀 이름과 달성률, 공헌이익 달성률을 연한 초록 상자로. 없으면 "해당 없음"
  4. 회의에서 다룰 팀: 「팀 살펴보기」에서 체크한 팀의 달성률, 공헌이익 달성률, 전년 대비, 비고만 표로. 기준에 걸린 값(달성률 95% 미만, 공헌이익 기준 미달, 전년 대비 감소 기준 이상)은 빨강
  5. 추가 확인사항: 팀마다 적어 둔 '확인할 것' 메모
  6. 핵심 메시지: 직접 적는 한 줄 칸
- [인쇄 / PDF] 버튼. 인쇄할 때는 회의 자료만 나올 것
- 체크한 팀이 없으면 "팀 살펴보기에서 회의에서 다룰 팀을 체크해 주세요" 표시

[필수 조건]
- 외부 라이브러리 없이, 인터넷 없이도 열릴 것
- 기존 기능(데이터 넣기·지우기·저장 방식 포함)은 그대로 둘 것
- 넣은 데이터와 메모는 밖으로 보내지 말 것
- 수정한 전체 파일을 .html로 내려받을 수 있게 할 것
⏳ 기다리는 동안 회의를 여는 핵심 메시지 한 줄을 적어 보세요.

만들어지면

데이터를 넣고, 「팀 살펴보기」에서 팀을 체크하고 '확인할 것'을 적습니다.
[회의 자료 만들기]를 눌러, 위에 적은 핵심 메시지를 넣습니다.
[인쇄 / PDF]로 한 장이 나오는지 봅니다.

맨 위 버튼 줄에 [이름 변경] 버튼을 추가합니다.
- 누르면 작은 창이 열리고, '부서 이름'과 '팀 대신 쓸 이름' 두 칸과 [취소] [적용] 버튼을 둘 것
- [적용]을 누르면 제목의 부서 이름과 화면의 '팀'이라는 말이 모두 바뀔 것 (예: 상품본부 → 가공식품팀, 팀 → 상품군)

- 이미 이름을 바꾸는 칸이나 버튼이 있으면 새로 만들지 말고, 이 버튼 하나로 합칠 것
- 데이터의 첫 열 이름이 '팀'이 아니어도 받을 것
나머지는 그대로 둘 것. 수정한 전체 파일을 .html로 내려받을 수 있게 할 것.
